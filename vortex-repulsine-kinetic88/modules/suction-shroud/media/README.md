# Project REPULSINE: Media, Suction Shroud & Venturi Intake Telemetry Index

This directory serves as the centralized repository for all visual assets, holographic intake funnel renders, coaxial fan twist layouts, and velocity acceleration charts for the **Passive Dorsal Intake Shroud Module (Module: suction-shroud)**.

---

## 📂 Internal Directory Manifest

*   **`README.md`:** This file (Shroud Media Blueprint Index Manual).
*   **`generate-blueprint.py`:** Standalone Python 3 asset script that programmatically compiles, verifies, and draws the uncompressed XML vector blueprint layout from scratch.
*   **`grid88-suction-shroud.svg`:** Native vector schematic blueprint mapping the 5:1 ratio centripetal shroud funnel, coaxial fan blades, and low-friction intake throats.

## 📸 Technical Asset Verification & Cleanroom Camera Protocols

To maintain absolute data integrity and verifiable prior-art across all open-source submissions to the public ledger, all laser-interferometer snapshots, material line traces, or airflow latency records uploaded here by the community must strictly adhere to these formatting rules:

1.  **High-Contrast Funnel Renders:** All CAD or computational fluid dynamics (CFD) exports must use a clean, dark-mode background profile to ensure that the 5:1 volumetric tapering lines are perfectly scannable on workshop monitors.
2.  **Fan Blade Micro-Documentation:** High-resolution photography demonstrating successful machining of the 85mm coaxial fan hub and its 22.5-degree blade twist must be shot under macro edge focus to check for structural anomalies.
3.  **Mass Flow Air Speed Logs:** Visual data overlays tracking the 14.2 kg/s air mass capture rate and the 15-second automatic starter fan cutoff window must link directly back to the parameters calculated inside the root `master-repulsine-twin.py` digital twin script.
