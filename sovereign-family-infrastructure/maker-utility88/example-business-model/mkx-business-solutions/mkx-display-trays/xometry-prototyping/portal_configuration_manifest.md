# 🏛️ Commercial Web Portal Slicing Configuration Checklist

Once your mesh files are compiled, log onto your selected digital manufacturing portal (e.g., Xometry.com) and drag and drop both `mkx_chassis_base.stl` and `mkx_branding_badge.stl` directly into the web ingestion dashboard. 

For each individual part, click the **Modify Part / Configure Material** drop-down panels and manually execute these precise parameter checkboxes to lock in your farm-equivalent slicing standards:

---

## 🛠️ INTERFACE CONFIGURATION LAYER A: `mkx_chassis_base.stl`

Select these precise drop-down menu items to match your cored, warp-free 85-gram structural specifications:

*   **Manufacturing Process Field:** Select **3D Printing** ──► **FDM (Fused Deposition Modeling)**
*   **Material Selection Field:** Select **Plastics** ──► **ASA** (Weatherproof Acrylic Styrene Acrylate)
*   **Color / Surface Finish Option:** Select **Matte Black** or Charcoal Gray Texture
*   **Layer Height Resolution Box:** Select **0.20 mm** (Standard / Balanced Print Tolerance)
*   **Infill Density Percentage:** Select **15% to 20%**
*   **Part Quantity Counter:** Set to **1 Unit**

---

## 💎 INTERFACE CONFIGURATION LAYER B: `mkx_branding_badge.stl`

Select these parameters to ensure the embossed corporate logo pops under showroom spotlights and resists daily industrial counter chemical wipedowns:

*   **Manufacturing Process Field:** Select **3D Printing** ──► **FDM** (Or select **SLA / Stereolithography** if you want an ultra-smooth, glass-like finish with zero visible layer lines)
*   **Material Selection Field:** Select **Plastics** ──► **PETG** or **ABS** (Or select Acrylic-like Clear Resin if utilizing SLA)
*   **Color / Surface Finish Option:** Select **Gold**, Vivid Brass, or Sapphire Blue to match the corporate MKX identity colorway palettes
*   **Layer Height Resolution Box:** Select **0.12 mm or 0.16 mm** (Fine / High-Resolution option to crisply define the embossed letter vectors)
*   **Infill Density Percentage:** Select **100% Solid Infill** (Guarantees deep color density and complete physical weighting)
*   **Part Quantity Counter:** Set to **1 Unit**

---

## 🏁 OVERVIEW CALIBRATION COMPLETE
Review your automatically generated instant price matrix. The combined cost across both parts should calibrate between **$35.00 and $55.00 USD** inclusive of shipping overheads. Process the payment checkout fields.
