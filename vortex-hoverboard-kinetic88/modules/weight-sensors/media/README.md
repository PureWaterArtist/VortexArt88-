## 📸 Technical Asset Verification & Cleanroom Camera Protocols

To maintain absolute data integrity and verifiable prior-art across all open-source submissions to the public ledger, all interferometer snapshots, voltage phase traces, or response latency records uploaded here by the community must strictly adhere to these formatting rules:

1.  **High-Contrast Sensor Renders:** All CAD or pressure-map simulation exports must use a clean, dark-mode background profile to ensure that the independent front and rear foot grids are perfectly scannable on workshop monitors.
2.  **Piezo Micro-Documentation:** High-resolution photography demonstrating successful lamination of the 250-micron PVDF film and its 1.2-micron fluoropolymer insulation must be shot under macro edge focus to check for surface anomalies.
3.  **Hydro-Actuation Latency Logs:** Visual data overlays tracking the 0.00 ms capillary signal lag and the strict $\leq 1.5\text{ ms}$ automatic detour response window must link directly back to the parameters calculated inside the root `master-skate-twin.py` digital twin script.
