# Project CARBON-SIEVE: Media, Kelp Ridges & RuBisCO Core Index

This directory serves as the centralized repository for all visual assets, holographic engineering schematics, 120-micron microfluidic air-tracking channels, and cross-sectional component diagrams for the **Biomimetic Solar-Driven Atmospheric Sieve Engine (Project Carbon-Sieve)**.

---

## 📂 Internal Directory Manifest

*   **`README.md`:** This file (Sieve Media Blueprint Index Manual).
*   **`generate-blueprint.py`:** Standalone Python 3 asset script that programmatically compiles, verifies, and draws the uncompressed XML vector blueprint layout from scratch.
*   **`grid88-sieve-specs.svg`:** Native vector schematic blueprint mapping the 4.5mm kelp corrugations, 120-micron solar tracks, and elastomeric mollusk collection tray.
